# 🧠 Breast Cancer Prediction using Logistic Regression

## 📌 Overview
This project is an end-to-end Machine Learning pipeline that predicts whether a tumor is **malignant (cancerous)** or **benign (non-cancerous)** using Logistic Regression.

The model is trained on a medical dataset and demonstrates the complete workflow of a real-world Data Science project—from data preprocessing to model evaluation.

---

## 🎯 Problem Statement
Early detection of breast cancer is crucial for effective treatment.  
This project aims to build a machine learning model that can classify tumors as **malignant or benign** based on various medical features.

---

## 📂 Dataset
- Dataset: Breast Cancer Dataset (from sklearn / UCI)
- Total Features: 30
- Target:
  - `0` → Malignant
  - `1` → Benign

## 🚀 Project Workflow

### 1. Import Libraries
Load essential libraries like pandas, numpy, sklearn.

### 2. Load Dataset
Load dataset using sklearn datasets.

### 3. Data Preprocessing
- Check missing values

### 4. Exploratory Data Analysis (EDA)
- Understand feature distribution  
- Correlation heatmap  

### 5. Train-Test Split
Split dataset into training and testing sets.

### 6. Model Building
Algorithm used: **Logistic Regression**

### 7. Model Training
Train model using training data.

### 8. Model Evaluation
- Accuracy Score  
- Confusion Matrix  

### 9. Prediction System
Build a system to predict new input data.
